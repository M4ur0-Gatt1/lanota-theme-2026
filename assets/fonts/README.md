# Fonts (Self-hosted)

Place Poppins font files here. Recommended minimal set:

- Poppins-Light.woff2 (weight 300)
- Poppins-Regular.woff2 (weight 400)
- Poppins-SemiBold.woff2 (weight 600)
- Poppins-Bold.woff2 (weight 700)
- Poppins-Black.woff2 (weight 900)

Optional legacy fallbacks:

- Poppins-*.woff

Paths are referenced in style.css as:

```
assets/fonts/Poppins-<Weight>.woff2
assets/fonts/Poppins-<Weight>.woff
```

After uploading the files, clear caches and hard refresh. The Google Fonts enqueue has been removed in functions.php.
